# Reproducibility Matrix

This matrix describes the repository command, not every historical reproduction exercise. CAP means Control Adjudication Protocol. `RECOMPUTED` identifies implemented checks; `RECOMPUTABLE_NOT_SCRIPTED` means the inputs are present but the command does not perform the calculation; `REPORTED_ONLY` means a saved result is provided without that command reproducing it. A result's presence in an expected table is not evidence of a fresh calculation. Categories apply to the named statistics, not automatically to every field or file in a row. See the [reproduction guide](reproduction_guide.md) for independent-implementation scope.

H1 sensitivity status takes precedence over numeric placeholders: `NOT_ESTIMABLE` and `OMITTED` rows do not supply estimated effects or inferential results. The H1_REMOVE_L5 category clarifies available inputs; it does not extend script coverage or claim a new reproduction pass. No forecast generation, R-Factor score generation, CAP classification generation, or H3 endpoint construction is reproduced by this repository.

For CAP resampling results, recovering a p-value arithmetically from a saved exceedance count does not reproduce the underlying random draws. The reported-only labels describe the absent resampling calculation, not absence of the paired evaluation observations.
